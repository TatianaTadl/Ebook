# Projeto EBOOK Gerado por I.A.s

Projeto com o objetivo de gerar um ebook digital com as facilidades das ferramentas de IA. Todos os prompts seguem abaixo.

## 💻 Tecnologias utilizadas no projeto

- [ChatGPT](https://chat.openai.com/) 
- [MonicaIm](https://monica.im/home/)
- [MetaAi](https://meta.ai)
- [PowerPoint](https://www.microsoft.com/en/microsoft-365/powerpoint)

## 🧠 Prompts


ChatGPT：

|   Ação   | prompt                                                                                                                                                                                                                                                                         |
| :------: | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
|  título  | Crie o título de um ebook sobre como praticar Pilates em casa, o ebook é do nicho fitness, o subnicho é pilates, o título deve ser épico e curto, e tenha uma temática da Mulher Maravilha no título, me liste 5 variações de títulos                                                        |
| conteúdo | Faça um texto para ebook, com foco em exercícios de Pilates que podem ser feitos em casa, listando os principais grupos musculares com exemplos de exercícios {REGRAS} Diga qual é o nome do exercício ou posição executada, explique sempre de uma maneira simples, deixe o texto enxuto, sempre traga exemplos de exercícios em casa sem aparelhos |
